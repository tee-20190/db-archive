DB archive privacy policy

Effective 14 October 2026.

Who uses it

DB archive is a personal tool. It is used by one person to archive their own files to their own Google Drive. It is not offered to the public.

What it can access

DB archive requests only Google's drive.file permission. This permits access to files the tool creates and files the user explicitly makes available to it. It does not grant access to the user's entire Google Drive. It does not request access to email, contacts, calendar, or any other Google data.

How the data is used

DB archive uses this access for three things:

  • to upload the user's own files;
  • to read the uploaded copies back and check that they match the originals exactly;
  • to download a copy again when the user asks for it.

Where the data stays

Archived files are stored in the user's Google Drive. The tool runs on the user's computer or cloud machines they operate, transferring files and archive records for uploading, verification and restoration. Working copies may remain on those machines until the user removes them. The tool does not sell data or use it for advertising or analytics.

Google API Services User Data Policy

DB archive's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

The user can remove DB archive's access at any time at myaccount.google.com/permissions. Removing access does not delete any file from Google Drive.

Changes

Any change to this policy will be published on this page with a new effective date.
