DB archive

DB archive is a personal file-archiving tool. It is used by one person to copy their own files from their own computer or cloud machines they operate into their own Google Drive. It then reads each copy back and checks that the copy matches the original exactly, so that the copy can be relied on.

The tool is not offered as a service, and it is not intended for use by anyone else.

DB archive uses Google's drive.file permission. This permits access to files the tool creates and files the user explicitly makes available to it. It does not grant access to the user's entire Google Drive.
